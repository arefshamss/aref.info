## ✨ Features

- 👤 Personal profile and introduction
- 📱 Responsive layout for desktop, tablet, and mobile
- 🎨 Minimal dark UI with a custom gold color palette
- 🖱️ Interactive 3D card tilt effect
- ⌨️ Typing animation
- 💫 Social link ripple effects
- 🔢 Animated counters
- 📬 Dedicated contact page
- 📧 Contact form with Web3Forms
- 🔎 SEO metadata and canonical URLs
- 👤 Schema.org Person structured data
- 🚫 Custom 404 page
- 🗺️ `robots.txt` and `sitemap.xml`

## ⚙️ JavaScript

The website uses vanilla JavaScript for interactive behavior, including:

- Interactive 3D card rotation based on pointer and touch movement
- Typing effect for the profile subtitle
- Animated number counters
- Ripple effects on social links
- Contact form validation
- Phone number input formatting
- Asynchronous contact form submission via Web3Forms
- Form loading, success, and error states

## 🔍 SEO

The website includes technical SEO foundations to improve its structure and search visibility:

- Page-specific titles and meta descriptions
- Canonical URLs
- Open Graph metadata
- Persian locale and RTL structure
- `robots.txt`
- `sitemap.xml`
- Schema.org Person structured data
- sameAs links for associated profiles and websites
- Custom 404 page
- Responsive viewport and theme metadata
